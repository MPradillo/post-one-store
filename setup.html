SETUP IN 3 STEPS

INSTALL ONCE. READY FOR A CLEANER TOMORROW.
JUST A FEW MINUTES.

1   INSTALL POST SNAP

Install POST SNAP once between the shower arm and shower head using the appropriate local-market seals/adapters.

2   MOUNT POST ONE

Clean and dry a compatible smooth wall surface, activate POST MOUNT and slide the unit onto the backplate.

3   FILL POST WASH

Refill POST WASH with your normal liquid laundry detergent and dock it into the left-side holster.
